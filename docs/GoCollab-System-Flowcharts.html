1. App Startup & Session Detection

flowchart TD
    Start([App Launch]) --> Init[Initialize Supabase Client]
    Init --> PKCE{URL has recovery/auth code?}
    PKCE -->|Yes| Handle[handleWebAuthCallback]
    Handle --> Session2{Session recovered?}
    Session2 -->|Reset password| Reset[/reset-password/]
    Session2 -->|Valid session| Shell[App Shell]
    PKCE -->|No| Check{Existing session?}
    Check -->|Yes| Role{Check role_id}
    Role -->|1 Member| MemberShell[Member Shell — 5 tabs]
    Role -->|2 Officer| OfficerShell[Officer Shell — 7 tabs]
    Check -->|No| Login[/login/]

2. Authentication (Email & Google OAuth)

sequenceDiagram
    actor User
    participant App as Flutter App
    participant Auth as Supabase GoTrue
    participant Google as Google OAuth

    alt Email / Password
        User->>App: Enter email + password
        App->>Auth: signInWithPassword()
        Auth-->>App: JWT session + user
        App->>App: Save session, route to Shell
    else Google Sign-In
        User->>App: Tap Continue with Google
        App->>Auth: signInWithOAuth(google, scopes: calendar.events)
        Auth->>Google: OAuth consent screen
        Google-->>Auth: Access + refresh tokens
        Auth-->>App: PKCE redirect with session
        App->>App: Store providerToken for Calendar API
        App->>App: Route to Shell
    end

3. Password Recovery (PKCE)

flowchart TD
    A[User taps Forgot Password] --> B[Enter email]
    B --> C[App calls resetPasswordForEmail]
    C --> D[Supabase sends recovery email]
    D --> E[User clicks link in email]
    E --> F[Browser opens localhost:5000/?code=...]
    F --> G[handleWebAuthCallback extracts code]
    G --> H{Code valid?}
    H -->|Yes| I[Exchange code for session]
    I --> J[Route to /reset-password]
    J --> K[User enters new password]
    K --> L[updateUser with new password]
    L --> M[Success — redirect to login]
    H -->|No| N[Show error snackbar on login]

7. QR Ticket Generation & Check-in

8. Google Calendar Sync

flowchart TD
    A[Event Detail — Add to Calendar] --> B{Google token available?}
    B -->|providerToken exists| C[Use Supabase providerToken]
    B -->|Cached token| D[Use GoogleTokenStorage]
    B -->|No token| E[Prompt Connect Google Calendar]
    E --> F[requestGoogleCalendarAccess]
    F --> C
    C --> G{Already synced?}
    D --> G
    G -->|No — gcal_event_sync empty| H[POST /calendars/primary/events]
    H --> I[Store gcal_event_id in gcal_event_sync]
    I --> J[Show success snackbar]
    G -->|Yes — event exists| K[PATCH to update event]
    K --> J
